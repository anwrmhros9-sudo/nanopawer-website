# Nanopawer Gaming & Comedy Website

موقع Nanopawer ثنائي اللغة (العربية والإنجليزية)، متجاوب مع الهاتف والكمبيوتر، مع وضع داكن وفاتح، شخصية القناة المرفقة، تكامل اختياري مع YouTube Data API، لوحة تحكم، قاعدة بيانات SQLite، ونموذج تواصل.

## التشغيل المحلي
1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى ملف باسم `.env`.
3. غيّر `ADMIN_USERNAME` و`ADMIN_PASSWORD` و`JWT_SECRET`. اجعل السر عشوائيًا وطويلًا (32 حرفًا على الأقل).
4. افتح الطرفية داخل مجلد المشروع ونفّذ:
   ```bash
   npm install
   npm start
   ```
5. افتح `http://localhost:3000`.
6. لوحة الإدارة: `http://localhost:3000/admin.html`.

قاعدة البيانات تنشأ تلقائيًا في `data/nanopawer.sqlite`. لا ترفع `.env` أو قاعدة البيانات إلى مستودع عام.

## تفعيل الفيديوهات والإحصائيات تلقائيًا
1. أنشئ مشروعًا في Google Cloud Console وفعّل YouTube Data API v3.
2. أنشئ API key، ثم احصل على Channel ID الصحيح للقناة (قد يختلف عن اسم المستخدم @NanoOPawer).
3. أضف إلى `.env`:
   ```
   YOUTUBE_API_KEY=مفتاحك
   YOUTUBE_CHANNEL_ID=معرّف_القناة
   ```
4. أعد تشغيل الخادم. عند فتح الصفحة، يجلب الموقع الإحصائيات وأحدث 6 فيديوهات عبر API.
لا يحتوي المشروع على مفاتيح API جاهزة أو أرقام مختلقة؛ ستظل البيانات الحقيقية غير متاحة حتى تضبط بياناتك.

## تفعيل البريد الإلكتروني
املأ بيانات SMTP في `.env` من مزود البريد الذي تختاره: `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS`, `CONTACT_TO_EMAIL`, `CONTACT_FROM_EMAIL`.
حتى قبل إعداد SMTP، تُحفظ رسائل التواصل في لوحة الإدارة. بعد إعداد SMTP، يحاول الخادم إرسال إشعار بريد إلكتروني. اختبر إعدادات البريد قبل إطلاق الموقع.

## النشر
المشروع يحتاج استضافة تدعم Node.js وخادمًا دائم التشغيل. عند النشر:
- أضف المتغيرات السرية من لوحة إعدادات الاستضافة، وليس في ملفات الواجهة.
- تأكد من وجود تخزين دائم لمجلد `data/` حتى لا تضيع قاعدة البيانات.
- فعّل HTTPS واستخدم كلمة مرور إدارة قوية.
- راجع شروط الخطة المجانية وحدودها؛ قد تتغير وقد لا تدعم التخزين الدائم.
- `render.yaml` مثال أولي لتسهيل إعداد الاستضافة، لكنه يحتاج مراجعة الإعدادات في حسابك.

## لوحة التحكم
- تسجيل الدخول من `/admin.html`.
- نشر أخبار وإعلانات وعناصر معرض بعناوين عربية وإنجليزية وصورة اختيارية.
- عرض رسائل نموذج التواصل وحذف المحتوى.
- مسارات الإدارة محمية برمز JWT مدته 8 ساعات، مع تحديد معدل محاولات الدخول.

## حدود النسخة الحالية
- الفيديوهات والإحصائيات تعتمد على YouTube Data API بعد إعدادها.
- لوحة الإدارة الحالية تدير الأخبار والإعلانات وعناصر المعرض ورسائل التواصل؛ الفيديوهات نفسها تأتي من يوتيوب.
- لم تُختبر إعدادات حسابات الاستضافة أو مفاتيح API الخاصة بك؛ هذه نقطة انطلاق كاملة المصدر وليست خدمة منشورة بالفعل أو تدقيقًا أمنيًا احترافيًا.
